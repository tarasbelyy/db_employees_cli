# Приложение для управления каталогом сотрудников компании


## Описание
Консольное приложение для управления базой данных персонала компании


## Инструкция 
Для работы с приложением в консоли введите:
```
python manage_db.py <cmd>
```

## Функциональность
- поддерживаются основные команды: init-db, drop-db, seed, list, add, update, delete, tree
- добавлены команда subtree для построения поддерева для заданного id сотрудника и команда delete-subtree для удаления всех сотрудников из поддерева (отдела)
- автоматически создается вакансия при delete(update позиции) сотрудника, на которую ссылаются подчиненные (только при их наличии)
- команда seed создает набор сотрудников с одним CEO, остальные должности генерируются в соответсвии с заданными пропорциями
- обрабатывается ряд ошибок в виде вывода сообщения, например: отсутствие id в таблице, нарушение порядка следования позиций при add/update

## Требования
Основные внешние библиотеки и фреймворки для Python, используемые в проекте: 
mimesis версии 19.1.0
psycopg2-binary версии 2.9.12
tabulate версии 0.10.0

Для хранения данных используется PostgreSQL.
